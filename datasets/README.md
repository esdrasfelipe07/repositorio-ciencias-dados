# Datasets da Disciplina de Ciência de Dados

Esta pasta armazena os arquivos de dados (.csv) utilizados ao longo das aulas práticas da Unidade 02:

| Arquivo | Aula | Descrição |
|---|---|---|
| `imoveis_sao_paulo.csv` | Aula 06 | Anúncios de aluguel em São Paulo (imputação e normalização) |
| `mtcars.csv` | Aulas 07, 08 e 09 | Atributos e consumo de automóveis |
| `iris.csv` | Aula 08 | Medidas morfológicas de flores |
| `penguins.csv` | Aula 08 | Dados biométricos de pinguins de Palmer |
| `sleep.csv` | Aula 08 | Estudo clínico de eficácia de medicamentos para sono |
| `titanic.csv` | Aula 08 | Dados demográficos e sobrevivência de passageiros |
| `california_housing.csv` | Aula 10 | Preços de imóveis da Califórnia (Regressão Linear) |
| `brca_pam50.csv` | Aula 11 | Expressão gênica em câncer de mama (Não Supervisionado) |

*Nota: Arquivos `.csv` brutos são excluídos do controle de versão pelo `.gitignore` conforme as boas práticas da disciplina.*
